# LightCore Dashboard

Vercel-ready dashboard frontend for configuring the LightCore Discord bot.

This folder is intentionally separate from the bot runtime. It is a static Next.js/Vercel-friendly starter that can later be connected to the bot API/database.

## Ticket setup philosophy
The dashboard is designed to make ticket setup guided instead of command-heavy: create a panel, add categories, choose staff roles, configure questions/forms, set logs/transcripts, and publish.
